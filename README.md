# Learning-Power-BI-Service
This repository is used to house various resources for the Learning Power BI Service course. These resources may be referenced in the course videos, but it IS NOT NECESSARY to follow along with all these files during the lessons. The files are provided just in case you want to try a few things out for yourself. 

The **Data** folder contains many of the raw data files that are used for building your semantic model. It is recommended that these files are copied to a OneDrive Location that your Power BI Service account can see. All lessons will assume that you have done this.
